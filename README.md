# Portfolio

> 나만의 이야기와 개발 경험을 담아가는 프론트엔드 개발자 포트폴리오

## 프로젝트 소개

프론트엔드 개발자로서의 역량과 프로젝트 경험을 보여주기 위한 개인 포트폴리오입니다.

단순히 프로젝트 결과만 보여주는 것이 아니라,
개발 과정에서 고민했던 내용과 문제 해결 과정을 함께 기록하는 것을 목표로 합니다.

디자인은 **Simple + Modern + Dandy**를 기본으로 하며,
**Persistence + Energy + Emotion**을 통해 저만의 개성을 표현합니다.

---

## 디자인 방향

### 분위기

- Simple
- Modern
- Dandy
- Persistence
- Energy
- Emotion

### 색상

전체적인 색상은 Gray를 기본으로 사용합니다.

보조 색상으로 Sky Blue를 사용하며,
텍스트에는 다음과 같은 색상을 활용합니다.

- Lavender
- Light Pink
- Deep Sky Blue

배경은 전체적인 가독성과 색상의 조화를 고려하여 밝은 색상을 기본으로 사용합니다.

### 폰트

- 마루 부리
- 네이버 폰트

폰트 크기와 여백 체계는 실제 화면을 제작하면서 조정합니다.

### 애니메이션

전체적으로 과하지 않은 애니메이션을 사용합니다.

특히 마법을 사용하는 듯한 느낌을 참고하여
빛, 잔상, 움직임 등의 효과를 활용하되
사용자의 콘텐츠 집중을 방해하지 않는 수준으로 구현합니다.

### 장식 및 이스터에그

장식 요소와 이스터에그는 초기 개발 단계에서는 우선순위를 낮게 두고,
전체적인 디자인과 콘텐츠가 완성된 후 필요한 요소를 추가합니다.

---

## 주요 구성

포트폴리오는 기본적으로 다음과 같은 영역으로 구성합니다.

1. 소개
2. About
3. Skills
4. Projects
5. Journey
6. Contact

개발 과정에서 콘텐츠의 흐름과 사용자 경험에 따라
필요한 영역을 추가하거나 변경할 수 있습니다.
